本目录是项目的 Python 应用包，按智能体、执行器、LLM、元数据、检索、评测和 Web 演示分类存放实现代码。

文件说明：
- __init__.py：Python 包初始化文件。
- requirements.txt：运行所需的 Python 依赖清单。
- agent：查询智能体、状态和节点实现。
- data：DuckDB 数据导入和校验工具及本地数据。
- executors：SQL 执行器实现。
- evaluation：智能体和检索评测脚本、案例与结果。
- llm：大模型客户端、配置、提示词和 SQL 生成模块。
- metadata：业务术语、指标、关系和模式目录。
- retrieval：元数据检索、向量索引和重排模块。
- sql：演示 SQL 查询及说明。
- tests：自动化测试。
- web：本地 Web 演示服务。
