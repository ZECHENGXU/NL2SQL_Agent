本目录存放项目自动化测试，覆盖契约校验、超时、检索、审批和 Web 健康检查。

文件说明：
- test_contracts.py：输出契约和 SQL 结构约束测试。
- test_case_timeout.py：案例和阶段超时测试。
- test_evaluator.py：Agent 评测器行为测试。
- test_metadata_retrieval.py：精确检索、RRF 融合和重排测试。
- test_query_approval.py：审批后执行和 SQL 再校验测试。
- test_web_llm_health.py：Web 层 LLM 健康检查测试。
- __init__.py：测试包初始化文件。
